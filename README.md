# Atlantic Cod Population Genetics
A reproducible population genetics project using publicly available microsatellite genotype data from Atlantic cod (*Gadus morhua*).
Project Statust. 
Project started (August 2026)
This repository documents my step-by-step learning journey in population genetics, Python, R, and Git/GitHub using a public Atlantic cod datase. The project is independent of my Master's thesis and uses only publicly available data.
